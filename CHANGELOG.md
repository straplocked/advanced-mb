# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-02-12

### Added
- Initial release of Advanced MB multiband compressor
- Up to 6 bands with dynamic add/remove via spectrum display
- Linkwitz-Riley crossover filters (6/12/18/24/36/48 dB/oct)
- Per-band compress and expand modes
- Three processing modes: Dynamic Phase, Linear Phase, Minimum Phase
- Percentage-based attack/release (Pro-MB style)
- Per-band sidechain options (Band/Free/External)
- Interactive multiband spectrum display with draggable crossovers and thresholds
- Real-time spectrum analyzer (Pre/Post/Pre+Post)
- 15 factory presets across Mastering, Mixing, Creative, and Starting Points categories
- MIDI Learn support for all parameters
- A/B comparison
- Oversampling (1x/2x/4x)
- Dry/wet mix (0-200%)
- Plugin formats: VST3, AU, CLAP, Standalone
